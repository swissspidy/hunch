Format version 2 ([ADR 0011](https://github.com/swissspidy/inkling/blob/main/docs/adr/0011-format-v2-columns.md)): shards keep each item's id, prior, publication time and section in binary columns, and the rest of its metadata (title, URL, tags, date, image) as separate JSON that the client decodes only for the items a call returns. Loading 100,000 items in Chromium takes about a third less main-thread time, the JS heap after loading is 85% smaller (33 MB → 5 MB), and recency no longer depends on how the visitor's browser parses dates. `inkling build`, the Astro integration and the WordPress plugin now write version 2 (manifest `formatVersion: 2`). The client reads versions 1 and 2. A page still running an older client refuses a version 2 manifest and keeps its server-rendered fallback until its script is updated, so upgrade the client before rebuilding. `decodeShard()` from `@swissspidy/inkling/format` returns the columns (`ids`, `prior`, `time`, `sections`, `section`), `count`, `version` and `item(i)`, alongside `items`.
