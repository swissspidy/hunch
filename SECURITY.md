# Security policy

Inkling's promise is that nothing about a visitor leaves their device. A way for a page using
Inkling to send profile or signal data over the network, to read another origin's Inkling data,
or to make the client run code from a manifest or shard is a vulnerability. Bugs in the build
step that let a crafted feed or page write outside the output directory are vulnerabilities too.

**Report vulnerabilities privately**, through
[GitHub's private vulnerability reporting](https://github.com/swissspidy/inkling/security/advisories/new),
not in a public issue. Please include the version, what you did and what happened. We aim to
answer within a week.

Only the latest release gets security fixes while Inkling is 0.x.
